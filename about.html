ABOUT NOLTAP / 01

심심할 때도,
필요할 때도.

놀탭은 심심할 때 즐길 거리와 일상에 필요한 작은 도구를 모아가는 공간입니다. 현재는 가입 없이 바로 즐기는 웹게임을 제공하며, 앞으로 실용적인 콘텐츠도 차근차근 추가할 예정입니다.

01 / JUST PLAY

가입 없이 바로

설치와 회원가입 없이 게임을 시작하세요. PC에서는 키보드와 마우스, 모바일에서는 터치로 플레이합니다.

02 / ONE MORE TRY

한 번 더 도전

짧은 플레이와 빠른 재도전으로 자신의 기록을 넘어보세요. 최고 기록과 효과음 설정은 같은 브라우저에서 이어집니다.

03 / READ & REACT

보고, 판단하고, 반응

무작정 빠르게 누르는 것만으로는 부족합니다. 규칙을 이해하고 상대의 움직임을 읽는 순간을 게임으로 만듭니다.

지금 플레이할 수 있는 게임

GAME 01 / COLOR & FOCUS

누르지 마!

문제에 제시된 색상 정보를 보고 알맞은 답을 고르는 판단력 게임입니다. 진행할수록 글자와 색, 배경이 섞여 집중력을 시험합니다. PC에서는 숫자 1–4, 모바일에서는 색상 선택 버튼을 사용하세요.

반응속도는 브라우저와 기기의 입력 지연에 영향을 받으므로 참고 기록으로 확인해주세요.

GAME 02 / READ THE BLADE

PARRY: LAST BLADE

정면에서 들어오는 검을 방향과 타이밍에 맞춰 쳐내는 3D 패링 게임입니다. 방향키 또는 WASD, 모바일 방향 버튼으로 막으세요. 방향별 베기와 지연 공격을 읽고 검이 실제로 들어오는 순간에 반응해야 합니다. 페이크 공격은 6번째 보스부터 등장합니다.

보스를 처치하면 체력이 일부 회복됩니다. 무한 생존에서는 더 많은 보스를 넘어 자신의 기록에 도전하세요.

결투 시작하기 ↗
GAME 03 / LUCK & LAUGHTER

통통! 해적 룰렛

3D 나무통을 돌려 구멍을 고르고 컴퓨터와 번갈아 칼을 꽂는 캐주얼 게임입니다. 16개 구멍 중 하나는 비밀 함정! 해적을 튀어나오게 한 쪽이 그 라운드에서 패배합니다. 안전한 칼 20점, 승리 100점으로 10라운드 총점을 겨뤄요. 전적은 이 브라우저에 저장되며 실제 돈이나 상품이 걸리지 않습니다.

기록과 함께 조금씩 나아가요

개인 최고 기록은 사용 중인 기기의 브라우저에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기로 이동하면 로컬 기록은 이어지지 않습니다. 온라인 랭킹의 연결 상태는 각 게임 화면에서 확인할 수 있으며, 서버에 연결되지 않아도 로컬 모드로 플레이할 수 있습니다.

놀탭은 게임의 조작감과 읽기 쉬운 화면을 계속 다듬고 있습니다. 오류나 개선할 점을 발견했다면 문의 페이지로 알려주세요. 서비스 운영자는 이호권입니다.
