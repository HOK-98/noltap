# Meshy GLB 교체 가이드

## 파일을 넣을 위치

프로젝트의 다음 경로를 사용하세요. 빌드할 때 dist/models로 복사됩니다.

```text
public/models/barrel.glb
public/models/pirate.glb
public/models/knife.glb
```

**해적 룰렛 전용 파일**입니다. 기존 패리의 parry-*.glb 파일은 그대로 둡니다. 파일을 넣고 개발 화면을 새로고침하거나 `npm run build` 후 다시 배포하세요. 세 파일 중 일부만 있어도 나머지는 미리보기 모델로 동작합니다.

## 모델 제작 권장사항

- **나무통:** 윗부분이 열려 있고 칼 구멍 16개가 실제로 만들어진 모델. 기본 배치는 세로 2줄 × 둘레 8개입니다. 통의 입구가 해적의 몸을 가리도록 제작하세요.
- **해적:** 귀여운 상반신 캐릭터, 통 밖으로 튀어나올 수 있는 독립된 모델. 통과 합쳐진 모델보다 별도 파일이 좋습니다.
- **칼:** 칼날·손잡이가 분리된 재질. 손잡이 재질 이름에 `handle` 또는 `grip`을 포함하면 선택 색상을 적용합니다. 이름은 config의 tintMaterials에서 바꿀 수 있습니다.
- 모델마다 한 개의 오브젝트로 합칠 필요는 없습니다. 사용하지 않는 카메라·조명·중복 메쉬를 정리하세요.
- 모바일을 위해 불필요한 고해상도 텍스처와 과도한 폴리곤을 줄이고, 가능하면 각 파일 2~5MB 안으로 준비하세요. 현재 GLTFLoader에는 Draco/KTX2 외부 디코더를 별도 구성하지 않았으므로 기본 GLB로 내보내세요.

## 크기와 방향 설정

`src/pirate/config.js`의 MODELS에서 조정합니다.

```js
barrel: {
  url: '/models/barrel.glb',
  height: 2.25, // 로딩 후 목표 높이
  position: [0, 0, 0],
  rotation: [0, 0, 0], // 라디안
  scale: 1,
}
```

GLB의 바운딩 박스를 기준으로 Y 높이를 맞추고 바닥을 Y=0으로 옮깁니다. 기본 좌표는 **Y가 위, 통 앞이 +Z**입니다. pirate.position은 통 로컬 좌표이며 칼의 위치·회전은 구멍 앵커 로컬 좌표입니다.

칼은 로딩 후 높이를 맞춘 뒤 기본적으로 X축 -90도 회전하여 칼날이 **-Z**, 손잡이가 **+Z**가 되도록 합니다. 파일마다 원본 방향과 피벗이 다르므로 rotation·position으로 조정하세요. 칼끝의 길이가 다르면 config.js의 SCENE.insertDepth(기본 .14)을 조정할 수 있습니다.

해적의 애니메이션이 포함돼 있다면 pirate.animation에 클립 이름을 지정하세요. 없으면 위치와 회전으로 튀어나옵니다. 튀어오르기 높이와 회전량은 SCENE.popHeight, SCENE.popSpin입니다.

## 16개 구멍 앵커

SLOTS 배열의 각 position과 normal은 barrelRoot 기준 로컬 좌표입니다. 예:

```js
{ id: 0, position: [0, 1.47, 1.035], normal: [0, 0, 1] }
```

position은 구멍의 중심, normal은 통 바깥을 향하는 단위 벡터입니다. ID는 0~15를 한 번씩만 사용하세요. 통에 실제 구멍이 어디 있는지 확인한 뒤 각 앵커를 맞춥니다. 모델의 position/rotation/scale을 바꾸면 앵커도 같은 좌표계에서 직접 맞춰야 합니다. 시각 통, 구멍 앵커, 삽입된 칼, 해적은 모두 같은 회전 부모에 연결돼 있어 드래그 회전 시 함께 움직입니다.

**구멍 없는 GLB를 프로그램이 자동으로 뚫지는 않습니다.** 현재의 검은 원과 테두리는 선택 마커입니다. 실제 구멍 표현이 필요하면 Meshy에서 구멍이 있는 통으로 수정하거나 Blender 등에서 Boolean 작업을 한 뒤 내보내야 합니다. 단순히 검은 마커를 덮는 것이 실제 기하 구멍을 생성하지는 않습니다.

## 교체 후 확인

1. 하단에 GLB 3/3 또는 사용자 GLB 적용 표시가 나오는지 확인합니다.
2. 정면과 뒷면을 돌려 16개 마커가 실제 구멍과 일치하는지 확인합니다.
3. 각 방향 칼끝이 구멍을 향하고 손잡이가 밖으로 나오는지 확인합니다.
4. 해적이 통 안에서 시작해 위로 튀어오르고, 라운드 초기화 시 돌아오는지 확인합니다.
5. 모바일에서 읽기 쉬운 크기와 프레임인지 확인합니다.
