# AdSense 준비 상태

- 게임별 정적 HTML 가이드 3개: 규칙·조작·기록·연습 팁·FAQ.
- 홈 카드와 게임 방법에서 상세 가이드로 이동 가능.
- 소개 페이지의 해적 룰렛 규칙을 현재 로컬 2~8인 한 판 방식으로 갱신.
- 개인정보처리방침은 현재 광고 미설치 사실과 향후 광고 쿠키·선택권을 구분해 설명.
- 빈 광고 예정 박스 제거. 실제 광고 코드·ads.txt는 아직 생성하지 않음.
- 사이트맵에 가이드 주소 추가.

## 신청 시 운영자가 마무리할 항목

1. AdSense 계정에서 noltap.com을 등록하고 요청되는 사이트 확인 방법 적용.
2. 계정의 실제 게시자 ID가 발급된 뒤 정확한 코드와 ads.txt를 적용.
3. 실제 광고 구성·타깃 지역에 맞춰 개인정보 안내와 필요한 동의 관리 설정 검토.
4. 광고는 내용이 있는 화면에 배치하고 게임 조작·플레이·재시작 버튼과 분리. 결과 팝업과 오류·로딩 화면에는 기본적으로 광고를 배치하지 않음.
5. 모델·이미지·음원 사용 권한 자료는 별도 보관. CC0 음원 출처는 public/audio/CREDITS.md에 기록.
6. 실제 사이트의 모바일 가독성, 모델 로딩, 랭킹 상태와 설명 일치를 점검한 후 심사 요청.

페이지나 글 수·트래픽 수치만으로 승인을 보장할 수 없으며, Google의 심사 결과에 따릅니다.
