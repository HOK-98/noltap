# 기사의 마지막 여행

놀탭의 네 번째 게임. `knight.html`에서 실행하는 정적 싱글플레이 나이트 투어 퍼즐입니다. 별도 DB나 PHP 변경은 없습니다.

## 실행

- 프로젝트 루트: `npm install`, `npm run dev` 후 `/knight.html`
- 배포 빌드: `npm run build`, 결과는 `dist/`
- 규칙 검증: `node --test test/knight-engine.test.js`
- 스테이지 재생성: `node tools/generate-knight.mjs` (생성 후 정답 검증 포함)

## 파일 역할

- `src/knight/engine.js`: 나이트 이동, 방문·완주 판정, 별점, KST 날짜·데일리 변환, DFS/Warnsdorff 풀이.
- `src/knight/solver-worker.js`: 힌트 탐색을 별도 Worker에서 수행. 정답을 찾은 경우만 힌트 제공. 탐색 시간/노드 초과와 완주 불가능을 구분.
- `src/knight/data/stages.json`: 30개 정적 스테이지. 크기·장애물·시작·마지막 도착·정답 경로·힌트 상한·테마.
- `src/knight/main.js`: 화면, 이동 잠금, 되돌리기, 일시정지, 해금, 데일리·도전, 브라우저 저장·합성 효과음.
- `src/knight/style.css`: 밝은 2.5D 타일·SVG 기사·여섯 테마·반응형 구성.
- `knight-guide.html`: 이용 방법 및 기록 안내.

## 규칙

일반은 순서대로 해금합니다. 초급 6개, 중급 8개, 고급 9개, 전문가 7개이며, 도전은 마지막 8개를 해금 제한 없이 제공합니다. 스테이지는 정답 경로의 시작/끝 일부를 장애물로 바꾸고 회전·반사해 구성했습니다. 모든 데이터는 나이트 이동·중복 방문 없음·장애물 제외·마지막 도착 조건을 자동 검증합니다. 시작 칸도 방문 수에 포함합니다.

힌트는 초급 8, 중급 4, 고급 2, 전문가 1회 상한입니다. 다른 경로를 선택한 경우 실제 완주 탐색을 수행하며, 1.8초 또는 35만 노드 내에 풀지 못하면 추측 힌트를 제공하거나 사용 횟수를 차감하지 않습니다. 전문가는 이동 가능 칸 강조를 끕니다.

힌트/되돌리기 0회는 별 3개, 힌트 1회 이하 및 되돌리기 2회 이하는 별 2개, 나머지는 별 1개입니다. 최고 별과 최단 시간은 독립 저장합니다. 새로고침은 진행 상태만 초기화합니다. 데일리는 KST 날짜별 결정적 변환이며 과거와 비슷한 구성이 다시 등장할 수 있습니다. 완료 이력으로 연속 완료 일수를 계산합니다. 온라인 랭킹·기기간 동기화는 없습니다.

## 배포

기존 운영 사이트에서는 `knight.html`, `knight-guide.html`, 해당 빌드 번들 및 Worker, 변경된 홈 HTML/번들, sitemap을 개별 업로드합니다. 서버 전용 랭킹 설정을 포함한 전체 폴더를 무작정 삭제하지 않습니다. 정적 파일만 필요하며 모바일 브라우저의 Worker와 LocalStorage를 사용합니다. 게임 콘텐츠에 광고 코드는 없습니다.
