# 통통! 해적 룰렛 — 실행과 운영

기존 놀탭 사이트에 추가한 세 번째 게임입니다. `/pirate.html`에서 실행됩니다. 게임 규칙과 기록은 브라우저에서 처리하며 MySQL 변경은 필요하지 않습니다. 운영 도메인에서는 `api/pirate-model.php`가 공개 GLB 세 개를 JSON으로 전달합니다. 로컬·GitHub Pages 미리보기는 정적 GLB 파일을 직접 사용합니다.

## 실행

프로젝트 루트에서 `npm install` 후 `npm run dev`를 실행합니다. 로컬 주소의 `/pirate.html`에 접속하세요. `npm run build`는 정적 배포용 `dist`를 만듭니다.

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `pirate.html` | 독립 게임 진입점, 검색·Open Graph 메타데이터 |
| `src/pirate/main.js` | 2~8명 설정·칼 색·차례 안내·한 판 결과 UI와 브라우저 저장 |
| `src/pirate/engine.js` | UI와 분리된 한 판 규칙, 비밀 함정, 턴 잠금 |
| `src/pirate/scene.js` | Three.js, Raycaster, 드래그 회전, 칼 삽입, 튀어오르기, GLTFLoader |
| `src/pirate/config.js` | 게임 시간, GLB 변환값, 16개 로컬 구멍 앵커 |
| `src/pirate/audio.js` | 외부 음원 없는 Web Audio 효과음, 음소거 |
| `src/pirate/style.css` | 나무·양피지 UI, 칼 버튼, 모바일 레이아웃 |
| `public/images/pirate-*.svg` | 직접 작성한 항구 배경과 해적 아바타 |

## 규칙과 공정성

- 16개 구멍 중 정확히 한 곳이 함정입니다. 매 라운드 `crypto.getRandomValues` 기반 균등 난수로 새로 정합니다.
- 2~8명이 한 기기에서 칼을 돌아가며 꽂는 로컬 패스 앤 플레이입니다. 각 플레이어는 서로 다른 이름과 칼 색을 선택합니다.
- 참가자마다 선택 색을 가진 칼을 사용하며, 실제 3D 칼의 손잡이 텍스처만 색칠해 금속 날과 가드를 보존합니다.
- 각 판은 첫 번째 참가자부터 시작합니다. 온라인 매칭이나 컴퓨터 상대는 없습니다.
- 칼을 꽂는 동안 턴을 잠그며, 이미 사용한 구멍은 클릭할 수 없습니다.
- 점수 없이 한 명이 함정에 걸리면 즉시 한 판이 종료됩니다. 결과에는 당첨자와 나머지 참가자의 무사 통과 여부를 표시합니다.
- 한 판 완료 시 이 브라우저의 플레이 횟수만 저장합니다. 새로고침하면 진행 중인 매치는 초기화됩니다. 참가자 설정과 완료 전적은 유지됩니다.
- 실제 돈·상품·베팅 없이 즐기는 캐주얼 게임입니다. 브라우저 실행 특성상 로컬 데이터를 개발자 도구로 조작하는 것까지 막는 서버 검증은 없습니다.

## Meshy 3D 모델

Meshy 웹에서 통·해적·칼을 생성하고 리메시·PBR 텍스처를 적용했습니다. 실제 모델은 `public/models/barrel.glb`, `pirate.glb`, `knife.glb`입니다. 총 약 4.84MB이며 통에는 16개 실제 구멍과 내부 공동을 로컬 CSG로 가공했습니다. 상세 제작 내역은 `PIRATE_ASSET_NOTES.md`를 참고하세요.

모델 로드에 실패하면 시작을 막고 재시도 안내를 표시합니다. WebGL을 사용할 수 없으면 번호 선택 모드로 플레이할 수 있습니다.

## 조작과 접근성

- 중앙의 번호 있는 구멍을 클릭/터치하면 실제 3D Raycaster로 판정합니다.
- 7px 넘게 드래그하면 회전만 하며 칼을 꽂지 않습니다. 회전 화살표도 제공합니다.
- 키보드는 Tab으로 현재 보이는 구멍에 이동하고 Enter로 선택합니다. 게임 방법의 번호 목록으로 16개 구멍을 선택할 수도 있습니다.
- 기기를 다음 참가자에게 건네 칼을 선택합니다. 탭이 숨겨지면 렌더링·삽입 애니메이션을 멈추고, 돌아오면 이어집니다.
- 효과음은 첫 사용자 입력 이후 활성화되며 ON/OFF 설정을 저장합니다.
- 모바일은 최대 8명 점수와 각 플레이어의 색을 함께 표시합니다. 아주 작은 높이의 화면은 가독성을 위해 세로 스크롤이 생길 수 있습니다.

## Hostinger 배포

최초 설치는 `npm run build` 후 dist 내용을 사이트 문서 루트에 배포합니다. 이후 게임 수정은 새 `pirate.html`이 참조하는 JS/CSS와 그 의존 파일, 변경된 API 파일만 올릴 수 있습니다. 의존 파일을 먼저 업로드하고 HTML을 마지막에 교체하세요. 모델을 수정하지 않았다면 기존 GLB를 다시 덮어쓸 필요가 없습니다. `api/pirate-model.php`는 운영 사이트에 반드시 포함합니다. Node.js 상시 서버가 필요하지 않고 DB SQL은 바뀌지 않습니다.

중요: 실제 서버에만 있는 `api/config.php`나 별도 인증 파일이 있으면 전체 교체 배포 전에 보존해야 합니다. 현재 프로젝트는 `config.example.php`만 포함합니다. 광고는 이 게임 플레이 화면에 넣지 않습니다.

기존 `robots.txt`를 유지하고 `sitemap.xml`에 `https://noltap.com/pirate.html`을 추가했습니다. 네이버 인증 메타 태그도 유지합니다.

향후 온라인 랭킹·멀티플레이는 엔진 위에 서버 권위의 세션과 턴 검증을 추가하는 방식으로 연결하세요. 현재 익명 전적은 이 브라우저의 LocalStorage에만 저장됩니다.
